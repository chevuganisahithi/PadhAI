# PadhAI - Your Agentic Study Assistant

Agentic AI Workflow converts lectures to notes.

Workflow: Input -> Listener (Whisper Tool) -> Scholar (Llama3 Tool) -> Mentor (Quiz Tool) -> Output

Tech Stack: Streamlit, Groq (Whisper + Llama3), LangChain

How to Run:
pip install -r requirements.txt
streamlit run app.py

Built for PPT: Includes BST Min-Max example
